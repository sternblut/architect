---
name: off
description: Turn the architect off on this Mac — the Telegram bot goes silent and the host stops. Use when the user asks to stop, turn off, disable or pause the architect or its Telegram bot.
---

Run `archi off`: the host and its start at login stop; sessions the architect started keep running. If the user also wants those sessions stopped, run `archi off --all` instead. Report the result in one line. Turning it back on is `archi on`; removing the plugin entirely is `/plugin uninstall architect@sapfir`.
